# Contributing

Thank you for contributing.

## Getting Started

1. Fork the repository.
2. Clone it locally and follow the project’s documented development workflow.
3. Follow the applicable [Pelagornis Styleguide](https://pelagornis.github.io/styleguide/)
   and existing project conventions.
4. Run relevant formatting, linting, and tests before opening a pull request.
5. Describe the purpose and verification of the change in the pull request.

## Development

- Document project-specific setup, checks, and release practices here after
  creating a repository from this template.

## Scope

This template does not prescribe a language, package manager, branch policy, or
release process. Add those decisions in the generated repository when known.
